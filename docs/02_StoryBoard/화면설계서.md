## 1. 화면 목록



화면별 구성 요소와 상세 동작은 Figma 화면설계서를 참조한다. 아래 목록은 조회 편의를 위해 화면 ID 순서로 정렬하며, Figma의 공간상 배치 순서와는 구분한다.

현재 구성은 주요 화면 33개, 확인창 7개, 상태 화면 9개로 총 49개이다. 상태 화면은 해당 화면의 오류·빈 목록·검증 결과 예시이며 별도의 기능 메뉴가 아니다. 공통 정책 CP-01은 49개 화면 수에 포함하지 않는다.

### 1.1 정보 구조와 공통 메뉴

| 사용자 | 이용 범위와 주요 메뉴 |
| --- | --- |
| 로그인 전 사용자 | 로그인·회원가입. 공개 도서·공개 게시물도 로그인 후 열람한다. |
| 일반 회원 | 내 서재, 도서 찾기, 독후감, 글귀, 저장한 글귀, 내 정보, 로그아웃 |
| 이용 정지 회원 | 일반 회원 기능 차단. 로그아웃과 본인 탈퇴를 위한 제한된 본인 확인만 허용 |
| 관리자 | 회원 관리, 도서 등록 요청, 공통 도서 관리, 신고 처리·이력, 추천 글귀, 월별 독후감 선정 |

일반 회원 공통 메뉴는 내 서재 → SCR-03, 도서 찾기 → SCR-05, 독후감 → SCR-13, 글귀 → SCR-16, 저장한 글귀 → SCR-19, 내 정보 → SCR-20으로 연결한다. 로그아웃은 인증을 폐기한 후 SCR-01로 이동한다.

## 3. 화면별 상세 설계

1장 화면 목록에서 해당 화면 ID의 Figma 디자인과 설계서를 열 수 있다. Figma 설계서의 빨간 설명 번호는 이 장의 표에서 같은 번호의 기능 영역에 대응한다.

### 3.0 공통 기준

공통 메뉴·권한·입력 검증·파일 처리·버튼 배치는 아래 기준을 한 번 정의하고 각 화면에 함께 적용한다. 화면별 표는 해당 영역의 추가 규칙을 기술한다.

### 3.0.1 입력 검증과 접근 권한

- 화면에서 확인 가능한 필수값·형식·길이·확인값이 유효하지 않으면 실행 버튼을 비활성화한다. 선택 항목은 비워 둘 수 있지만 입력한 값은 검증한다.
- 비밀번호 일치·아이디/닉네임/전화번호 중복·작성자·서재 등록 여부·관리자 권한은 서버에서 최종 검증한다. 버튼 숨김만으로 권한 검증을 대체하지 않는다.
- 실패 시 오류를 해당 입력이나 작업 근처에 안내하고 나머지 작성 값과 가능한 조회 조건을 유지한다. 빈 목록·검색 결과 없음·조회 실패를 구분한다.
- 비공개 독후감은 본인만 열람하고 관리자도 열람하지 않는다. 익명 글의 계정·프로필은 일반 회원에게 노출하지 않는다.
- 관리자 권한으로 필요한 익명 작성자를 확인하는 경우 목적과 접근·조치 이력을 기록한다.

### 3.0.2 회독·글·반응의 일관성

- 새 회독 생성과 회독별 최종 독후감 최초 작성은 동시·중복 요청에서도 하나만 생성되도록 서버에서 제약과 검증을 적용한다.
- 독후감 공개 방식 변경·글 삭제·관리자 숨김 시 공개 목록·검색·추천·월별 선정 노출에 현재 상태를 반영한다.
- 글귀 오늘의 집계 기간은 KST 당일 00시부터 집계 시점까지이고 10분마다 갱신한다. 경쟁 순위 1, 2, 2, 4를 적용하며 rank ≤ 10인 글을 모두 표시하여 동점으로 10개를 초과해도 포함한다.
- 글귀 급상승은 최근 1시간과 직전 1시간의 점수 차이를 사용한다. 구간 점수는 조회수 + 유효 좋아요 수 × 10이며, 차이가 0보다 큰 글만 표시한다.
- 좋아요 취소는 원래 등록 시각이 속한 기간 집계에서 차감하고 다음 순위 갱신에 반영한다. 저장은 이 점수에 포함하지 않는다. 삭제·숨김 글은 즉시 일반 노출에서 제외한다.
- 독후감 정렬·선정 기준과 글귀 순위 기준을 혼용하지 않는다. 월별 선정 대상 월은 최초 작성 시각을 기준으로 판단한다.

### 3.0.3 파일 처리·삭제·보존

- 외부 표지 URL과 로컬 표지 파일을 구분한다. 표지 미제공·불러오기 실패 시 기본 표지로 대체하며 원본 비율을 유지한다.
- 표지 교체·삭제는 데이터베이스 변경과 정리 대상을 함께 기록한 후 파일 정리를 성공할 때까지 재시도한다. 취소한 수정은 기존 표지에 반영하지 않는다.
- 공통 도서에서 사용 중인 표지 파일은 개인 계정·서재·요청 삭제와 분리하여 유지한다.
- 일반 자료 삭제와 신고·경고·제재 최소 이력 보존을 구분하고, 당사자별 탈퇴일 기준 최대 90일 이내에 식별 연결·관련 자료를 삭제한다.
- 모든 보존 목적·기간이 끝나면 공통 신고 이력도 삭제한다. 탈퇴 회원 이력을 일반 회원정보 조회에 노출하지 않는다.

### 3.0.4 공통 화면 배치

- 입력·검색·목록의 좌우 기준선을 맞춘다. 아이디 중복 확인은 아이디 입력칸 오른쪽에 배치한다.
- 일반 작업 버튼은 본문·마지막 입력 영역 아래 24px 간격으로 두고 화면 바닥에 고정하지 않는다. 오른쪽은 취소·보조 작업 → 저장·주요 실행 순서이며 버튼 사이 간격은 12px이다.
- 삭제·탈퇴 진입 버튼은 본문 왼쪽 기준선에 두고 일반 작업은 같은 행 오른쪽에 둔다. 최종 확인창에서는 취소 → 최종 실행 순서로 오른쪽에 배치한다.
- 내 서재 더보기는 목록 아래 중앙에 둔다. 최종·날짜별 독후감 쓰기는 각 목록 아래 오른쪽에 두고 동일한 크기를 사용한다.
- 책 카드의 표지·제목·저자·회독 상태·별점은 가운데 정렬한다. 제목은 최대 두 줄까지 표시하고 초과하면 말줄임하며 상세에서 전체 제목을 확인한다.
- 게시물 통계와 행동을 구분한다. 순위는 글귀 본문과 별도 줄에 표시하고 좋아요·저장·신고·수정은 대상의 상태와 권한에 맞게 제공한다.
